# 动作运镜库（Motion）

> Seedance 部分依据火山引擎官方的《Seedance 2.0 提示词指南》，以及 VSC 在 Seedance 2.5 上的实测经验整理。

## 这个库是做什么的

这个库只用来参考，你只做三件事：

1. **讲清楚**这个动作或运镜是什么样的。
2. **给链接**：原片或效果视频的播放链接，让用户自己看。
3. **用户需要时**，按 Seedance 的架构写复刻这个动作的提示词。

不要调用任何视频模型。深度视频和白模视频请引导用户到网站详情页下载（工具结果里的 `download` 字段）。

## 1. 找素材

1. 先问清用户要拍什么、怎么拍。"拍什么"放进 `filters.content_type`，"怎么拍"放进关键词。例如：`vsc_search({ library: "motion", filters: { content_type: "dance" }, keywords: ["卡点", "环绕", "beat sync"] })`。
2. 不确定有哪些分类时，调用 `vsc_browse({ library: "motion" })`。分类包括子类，比如 `combat-kicks`（腿法）、`camera-tracking`（跟拍）。
3. 给用户 3–5 个候选，写明标题、一句话描述、时长和比例。
4. 用户选定后，调用 `vsc_get_motion({ id })`。

## 2. 讲清动作

`vsc_get_motion` 返回的 `usage_guide` 是编辑整理的用法，里面包括：
- 动作描述或镜头描述：可以直接复制。
- `reason`：为什么推荐这种用法。
- `steps`：具体步骤。
- `composition`：前后怎么衔接。
- `reference`：什么时候要上传参考视频。

先根据这些内容和标题、描述，向用户简要说明这段素材拍了什么、用了什么手法。然后附上播放链接（通过 `vsc_media({ library: "motion", id, slot: "preview" | "result" })` 获取，5 分钟内有效）和网站详情页链接。

注意：你看不到视频画面，只能读到文字。不要编造文字里没写的动作细节。

## 3. 何时写提示词

找到素材后，**用户需要时**再写提示词，不要每次都主动写。写之前先确认两件事：
- 用户想保留素材里的哪些部分：整段动作、只要运镜，还是只要某个节拍。
- 用户自己的角色和场景是什么。

如果文字信息不够写分镜，就请用户看完视频后用一两句话描述关键动作，再根据描述来写。

## 4. 写 Seedance 提示词

### 素材分配

官方建议素材总数控制在 4–5 个以内，每个素材都要说明用途：

| 素材 | 用途 |
|---|---|
| 图片1 | 锁定角色。建议用大头照，避免用多视图拼图 |
| 视频1 | VSC 的深度视频或白模视频，只用来参考动作和运镜 |
| 图片2（可选） | 确定场景基调 |
| 音频1（可选） | 节奏和氛围 |

### 写作规则

1. **定义主体**：用 2–3 个稳定的静态特征定义主体，并给它一个标签，后文都用这个标签。例如："将图片1中穿白色短上衣、黑色高马尾的女生定义为主体1"。
2. **引用参考视频**：写"参考视频1中的人物动作与运镜节奏"。如果是编辑或延长原视频，直接写"视频1"，不要加"参考"二字。
3. **必须写这句**："视频1仅作为动作与运镜参考，不参考其灰白/深度画面的颜色与质感。"
4. **按镜头分段**：写成"镜头1 / 镜头2 / 镜头3"，按事件发生的先后排列。官方说明精确到秒的控制不稳定，所以默认只按镜头分段；用户需要时，再给每个镜头加上大致的时间段。
5. **每个镜头只用一种运镜**，不要在同一个镜头里同时写推、拉、摇、移。运镜用标准术语，例如推镜、拉镜、横移、环绕、跟拍、升降、甩镜、固定镜头。
6. **动作要写到身体部位**：写清手、腿、头、肩怎么动，以及动作的幅度、速度和力度，并写出前后动作的承接关系。情绪要用具体的身体细节来表现。素材里的动作描述可以直接拿来用，同时把左右方向统一成以角色自身为准。
7. **结构顺序**：主体、动作细节、场景环境、光影色调、镜头运镜、视觉风格、画质、约束条件。视觉风格可以从风格图谱里取。
8. **约束条件**：无字幕、无水印、无 Logo，肢体比例正常，人物不换脸。
9. **符号约定**：`()` 表示音乐，`<>` 表示音效，`{}` 表示台词，`[]` 表示字幕。台词不要中英文混用。

### 模板

```
将图片1中{2–3个静态特征}的{人物}定义为主体1。
参考视频1中的人物动作与运镜节奏，视频1仅作为动作与运镜参考，不参考其灰白/深度画面的颜色与质感。
场景：{地点、地面、天气、关键道具}，{光影色调}。风格：{视觉风格}，{画质描述}。

镜头1：{一种运镜}。主体1{部位动作，含幅度和速度} → {承接动作}，{位置或空间关系}。<{音效}>
镜头2：{一种运镜}。主体1{……}。
镜头3：{一种运镜}。主体1{……}，{收尾动作或定格}。

(背景音乐：{节奏或风格})
约束：无字幕，无水印，无Logo，肢体比例正常，人物不换脸。
```

### 交付内容

1. 素材说明：附播放链接和详情页链接。
2. 完整的提示词：放在代码块里，可以直接复制。
3. 素材清单：图片1、视频1 等分别需要用户准备什么，视频1 去哪里下载。
4. 2 条翻车预案，写成"如果出现 X，就把 Y 改成 Z"。可以参考 `usage_guide.reference` 和 `composition`。

## 非会员

非会员只能使用约 10% 的固定样例。被锁定的条目不要凭标题去推测动作细节，请引导用户开通会员。
